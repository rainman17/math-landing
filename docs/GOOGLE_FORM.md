# Подключение Google-формы

Заявки с сайта отправляются прямо в Google-форму. Ответы появляются во вкладке «Ответы» и, если связать форму с таблицей, в Google-таблице. Сервер не нужен.

## 1. Создайте форму

[forms.google.com](https://forms.google.com) → новая форма. Добавьте **11 вопросов** именно в таком порядке.

**Все вопросы — тип «Текст (строка)» или «Текст (абзац)».** Не используйте «Один из списка», «Несколько из списка» и «Раскрывающийся список». Сайт сам присылает готовые значения, а Google отклоняет ответ, если значение не совпало с вариантом из списка. Сайт об этом не узнает, и заявка тихо потеряется.

Обязательными в форме вопросы не делайте: обязательность проверяет сайт.

| № | Вопрос | Тип | Что пришлёт сайт |
|---|---|---|---|
| 1 | Имя родителя | строка | Анна |
| 2 | Телефон или Telegram | строка | +79991234567 или @username |
| 3 | Email | строка | anna@mail.ru |
| 4 | Класс ребёнка | строка | 7 |
| 5 | Интересующий уровень | строка | Понимание школьной алгебры / Не знаю |
| 6 | Главная цель | строка | Понять школьную алгебру |
| 7 | Удобное время | строка | Будни после школы (15–18), Выходные (10–15) |
| 8 | Часовой пояс | строка | UTC+3 |
| 9 | Комментарий | абзац | свободный текст родителя |
| 10 | Согласие на обработку данных | строка | Да — версия «…», дата и время |
| 11 | Источник | строка | utm_source=yandex; utm_campaign=…; откуда=…; устройство=телефон |

В настройках формы:

- **«Ответы» → выключите «Собирать адреса электронной почты»** и «Ограничить одним ответом». Иначе Google потребует вход в аккаунт, и ответы с сайта не примутся.
- Форма должна принимать ответы (переключатель «Принимать ответы» включён).
- По желанию: «Ответы» → «Связать с Таблицами» — заявки будут падать в Google-таблицу.

## 2. Получите идентификаторы полей

1. В форме: меню ⋮ → **«Получить ссылку на заполненную форму»**.
2. В каждое поле впишите что угодно, например `1`, `2`, `3`… — так проще сопоставить поля.
3. «Получить ссылку» → «Копировать ссылку».

Ссылка выглядит так:

```
https://docs.google.com/forms/d/e/1FAIpQLSc...XYZ/viewform?usp=pp_url&entry.1234567890=1&entry.2345678901=2&...
```

- `1FAIpQLSc...XYZ` — ID формы;
- `entry.1234567890` — идентификатор вопроса, в который вы вписали `1`, и т.д.

Эту ссылку можно просто прислать разработчику — по ней подставляются все значения.

## 3. Пропишите их на сайте

Откройте `assets/js/config.js`:

```js
googleForm: {
  action: 'https://docs.google.com/forms/d/e/1FAIpQLSc...XYZ/formResponse', // viewform → formResponse
  fields: {
    parentName: 'entry.1234567890', // вопрос 1
    contact: 'entry.2345678901',    // вопрос 2
    // … и так далее до source
  },
},
```

Обратите внимание: в адресе `viewform` заменяется на **`formResponse`**.

Пока в конфиге стоят заглушки, сайт не отправляет заявки и показывает подсказку «Отправка ещё не настроена».

## 4. Проверьте

1. Откройте сайт, заполните форму, отправьте.
2. Во вкладке «Ответы» формы должна появиться заявка — обычно сразу.
3. Если заявка не появилась:
   - проверьте, что `action` заканчивается на `/formResponse`;
   - проверьте, что все вопросы текстовые и не обязательные;
   - проверьте, что выключен сбор email и вход в аккаунт;
   - проверьте каждый `entry.…` по ссылке из шага 2.

## Ограничения

- Google не сообщает сайту, принят ли ответ. Сайт показывает «Заявка получена», когда запрос ушёл. Поэтому важно один раз проверить приём по шагу 4 и не менять типы вопросов потом.
- Если в форме удалить вопрос и создать заново, у него будет новый `entry.…` — обновите `config.js`.
- **Персональные данные.** Ответы хранятся на серверах Google за пределами РФ. По 152-ФЗ персональные данные граждан РФ при сборе должны записываться в базы на территории РФ. Решение о допустимости такой схемы — за владельцем и юристом. Альтернативы с хранением в РФ — Яндекс Формы или полная версия сайта (ветка `full`) с базой на российском хостинге.
