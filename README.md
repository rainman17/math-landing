# «Как рождается алгебра» — статическая версия лендинга

Упрощённая версия сайта курса «Мысли как математик» без сервера и базы данных: HTML, CSS и немного JavaScript. Заявки уходят в Google-форму.

Полная версия с админкой и обработкой заявок — ветка `main`. Исходные документы проекта (ТЗ, путь пользователя, макеты, план) — [`docs/requirements/`](docs/requirements/).

## Как запустить

### 1. Что нужно

- **Node.js 18 или новее.** Проверить: `node -v`. Установить: [nodejs.org](https://nodejs.org) или `brew install node`.
- `npm install` для запуска **не нужен**: зависимостей нет, они нужны только для тестов.

### 2. Открыть статическую версию

Статика лежит в ветке `static-landing` того же репозитория, что и полная версия:

```bash
cd ~/Desktop/site/landing
git checkout static-landing
```

В ветке `main` этих файлов нет — там полная версия с бэкендом.

### 3. Запустить

```bash
npm start
```

Откройте в браузере **http://localhost:4173**.

### 4. Открыть с телефона в той же Wi-Fi-сети

```bash
npm run start:lan
```

На телефоне откройте `http://<IP компьютера>:4173`. IP на Mac можно узнать командой `ipconfig getifaddr en0` (например, `192.168.40.60`). Если macOS спросит, разрешить ли входящие подключения для `node`, — нажмите «Разрешить».

### 5. Остановить

`Ctrl+C` в окне терминала, где запущен сервер.

Если сервер запущен в фоне или терминал уже закрыт:

```bash
kill $(lsof -tiTCP:4173 -sTCP:LISTEN)
```

### Если что-то не так

| Проблема | Что делать |
|---|---|
| `EADDRINUSE: address already in use` | Порт 4173 занят. Остановите старый сервер командой выше или запустите на другом порту: `node scripts/serve.mjs 5000` (с телефона — `node scripts/serve.mjs 5000 --lan`) |
| `npm start` запускает Next.js, ругается на сборку, или в папке нет `index.html` | Открыта ветка `main` с полной версией. Переключитесь: `git checkout static-landing` |
| С телефона не открывается | Компьютер и телефон должны быть в одной сети; запуск именно через `npm run start:lan`; проверьте разрешение для `node` в «Системные настройки → Сеть → Файрвол» |
| Нет Node.js | Подойдёт любой статический сервер, например `python3 -m http.server 4173` (своя страница 404 работать не будет) |

> **Важно:** даже при локальном запуске заявки из формы уходят в **настоящую** Google-форму «Заявки». Тестовые отправки потом удаляйте во вкладке «Ответы» формы.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | лендинг: первый экран, ситуации, методика, уровни и цены, формат, преподаватель, «Персональный маршрут», как попасть в группу, доверие, FAQ, форма заявки |
| `privacy.html`, `consent.html` | черновики политики и согласия (заменить согласованными текстами) |
| `404.html` | страница «не найдено» |
| `assets/js/config.js` | **настройки**: Google-форма, Метрика, Telegram, срок ответа, версия согласия |
| `assets/js/app.js` | форма и проверка полей, отправка в Google, черновик формы, Метрика и баннер cookie, UTM, меню |
| `assets/css/styles.css` | стили; шрифт Golos Text — локальные файлы в `assets/fonts` |
| `robots.txt`, `sitemap.xml` | для поисковиков |
| `docs/GOOGLE_FORM.md` | как создать и подключить Google-форму |

Зависимостей и сборки нет — папку можно выложить на любой хостинг как есть.

## Форма заявки

Одна короткая форма:
- обязательные поля: имя, телефон или Telegram, email, класс, цель, согласие;
- необязательные: уровень, удобное время, часовой пояс, комментарий.

Как она работает:
- **Проверка полей** — в браузере, сообщения об ошибках показываются рядом с полями.
- **Уровень с карточки.** Кнопка на карточке уровня прокручивает к форме и подставляет этот уровень.
- **Черновик.** Введённое сохраняется в браузере и не теряется при обновлении страницы; после отправки черновик очищается.
- **Защита от ботов.** Скрытое поле-ловушка и отсев форм, отправленных быстрее 2 секунд.
- **Источник визита.** UTM-метки и устройство уходят в поле «Источник».

Заявки уходят в Google-форму «Заявки» (`assets/js/config.js`), приём проверен реальной отправкой. Если форму пересоздать, ID полей поменяются — порядок обновления в `docs/GOOGLE_FORM.md`.

## Что заполнить перед запуском

Всё, что нужно заменить, помечено `ЗАМЕНИТЬ` или `[ЗАПОЛНИТЬ]`:

- [x] `assets/js/config.js` — Google-форма подключена
- [ ] `assets/js/config.js` — номер Метрики, ссылка на Telegram, реальный срок ответа
- [ ] `index.html` — имя, фото и биография преподавателя, текст обращения, реквизиты в подвале
- [ ] `example.ru` → домен сайта в `index.html`, `robots.txt`, `sitemap.xml`
- [ ] `privacy.html`, `consent.html` — согласованные с юристом тексты; после этого убрать `noindex` и баннер «на согласовании»
- [ ] Цены, статусы набора, доплаты — прямо в `index.html` (поиск по «₽» и «Набор открыт»)

Фото преподавателя: положите файл в `assets/img/` и замените заглушку `teacher-placeholder` в `index.html` на `<img>` (пример — в комментарии рядом).

## Тесты

```bash
npm install          # Playwright
npx playwright install chromium   # один раз
npm test
```

Проверяются:
- вёрстка на 360, 768 и 1280 px и загрузка шрифта;
- ошибки у полей;
- поведение без настроенной формы;
- точный состав полей, уходящих в Google: запрос перехватывается, в Google ничего не отправляется;
- черновик формы;
- обрыв сети;
- ловушка для ботов;
- мобильное меню и закреплённая кнопка.

## Аналитика

Номер счётчика — `metrikaId` в `config.js`. Если `requireCookieConsent: true`, Метрика включается только после согласия в баннере cookie.

| Событие (цель «JavaScript-событие») | Когда |
|---|---|
| `cta_click` | клик по кнопке «Подобрать группу» (параметры: location, level) |
| `form_complete` | заявка отправлена (level, goal, class) |
| `contact_click` | клик по ссылке на Telegram |

## Хостинг

Подходит любой статический хостинг: Яндекс Object Storage + CDN, Selectel, Netlify, GitHub Pages, обычный nginx. Выкладывать всю папку, кроме `node_modules`, `tests`, `scripts` и `docs`.

`404.html` использует пути от корня сайта, поэтому сайт лучше размещать в корне домена, а не в подпапке.

## Ограничения статической версии

- Нет админки: тексты и цены правятся в `index.html`.
- Нет уведомлений преподавателю: включите в Google Forms «Ответы» → ⋮ → «Получать уведомления о новых ответах».
- Google не подтверждает сайту приём ответа (см. `docs/GOOGLE_FORM.md`), поэтому после подключения обязательно проверить приём вручную.
- Ответы Google Forms хранятся за пределами РФ — см. раздел «Персональные данные» в `docs/GOOGLE_FORM.md`.
